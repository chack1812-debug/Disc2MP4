# Disc2MP4 取扱説明書

自作(ホームビデオ)の DVD・ブルーレイを、パソコンやスマホで見やすい `.mp4` に変換するソフトです。低解像度の映像でも見やすくなるよう、ちらつきの除去と拡大(既定は 1080p)を自動で行います。

- 対象: 自分で作った・録画したディスク(コピーガードなし)
- 対象外: 市販ディスクなどコピーガードのあるもの

## 1. 用意するもの

| もの | 説明 |
|---|---|
| `disc2mp4.exe` | このソフト本体(「ビルド」の手順で作る。`target\release\disc2mp4.exe`) |
| ffmpeg | 実際の変換を行う無料ソフト。`ffmpeg.exe` と `ffprobe.exe` が必要 |
| 変換するディスク | DVD は `VIDEO_TS` フォルダ、ブルーレイは `BDMV` フォルダが入っているもの |

### ffmpeg の準備

`ffmpeg.exe` と `ffprobe.exe` が入っているフォルダを、環境変数 PATH に追加しておきます(例: `C:\Program Files (x86)\ffmpeg\bin`)。確認方法は、コマンドプロンプトか PowerShell で次を実行して、バージョンが表示されれば OK です。

```
ffmpeg -version
```

PATH に追加したくない場合は、変換のたびに `--ffmpeg "C:\...\ffmpeg.exe"` でパスを教えることもできます(`ffprobe.exe` は同じフォルダから探します)。

### ビルド(最初の 1 回)

Rust(cargo)が入っている環境で、このフォルダで次を実行します。

```
cargo build --release
```

`target\release\disc2mp4.exe` ができます。このファイルだけを好きな場所にコピーして使えます。

## 2. 基本の使い方

操作は 2 つだけです。コマンドプロンプトか PowerShell を開いて実行します。

### ① 中身を確認する(list)

```
disc2mp4 list E:\
```

表示例:

```
Dvd: E:\VIDEO_TS
  [1] VTS_01            13:56  720x480  1 ファイル
```

- `[1]` はタイトルの番号、`13:56` は長さ(分:秒)、`720x480` は元の解像度です
- 1 枚のディスクに複数の動画が入っている場合は、複数行になります
- 10 秒未満のタイトルには「短いため既定では除外」と表示されます(メニューの残りなどのため)

### ② 変換する(convert)

```
disc2mp4 convert E:\ -o D:\動画\旅行2010.mp4
```

進捗が `43%` のように表示され、100% になれば完了です。変換が終わるまで、ウィンドウは閉じないでください。

`-o` を付けなかった場合の出力先:

| 指定したパス | 出力先 |
|---|---|
| `D:\ビデオ\2010旅行`(中に VIDEO_TS がある) | `D:\ビデオ\2010旅行.mp4`(そのフォルダの隣) |
| `E:\`(ドライブ直下) | 今いるフォルダに `disc.mp4`(ディスクには書き込めないため) |

ドライブ直下から変換するときは、`-o` で出力先を指定するのが確実です。

## 3. ディスクの指定のしかた

次のどれでも同じように動きます。

- ドライブ: `E:\`
- ディスクの中身をコピーしたフォルダ: `D:\ビデオ\2010旅行`(中に `VIDEO_TS` または `BDMV` がある)
- `VIDEO_TS` / `BDMV` フォルダそのもの: `D:\ビデオ\2010旅行\VIDEO_TS`
- 日本語や空白を含むパスも使えます(空白があるときは `"..."` で囲んでください)

ISO ファイルは直接読めません。Windows でダブルクリックしてマウントし、できたドライブを指定してください。

## 4. オプション

| オプション | 意味 | 既定 |
|---|---|---|
| `-o`, `--out` | 出力先。`.mp4` で終わる名前ならそのファイル、そうでなければフォルダ | 上の表のとおり |
| `--title N` | 変換するタイトル番号(`list` で確認) | 一番長いタイトル |
| `--all` | 全タイトルを `名前_title01.mp4`、`_title02.mp4`… と別々に変換 | 本編 1 本だけ |
| `--height` | 出力の高さ。`720` / `1080` / `keep`(元のまま) | `1080` |
| `--quality` | `high`(高画質・遅い) / `standard`(標準・速い) | `high` |
| `--deinterlace` | ちらつき除去。`auto`(自動) / `on` / `off` | `auto` |
| `--force` | 既にある出力ファイルを上書きする | 上書きしない |
| `--ffmpeg` | ffmpeg のパス(PATH に無いとき) | PATH 上の ffmpeg |

例:

```
disc2mp4 convert E:\ -o D:\out\a.mp4 --height 720 --quality standard   # 速く・小さく
disc2mp4 convert E:\ --all -o D:\out                                    # 全タイトルを D:\out に
disc2mp4 convert D:\copy --title 2 -o D:\out\second.mp4                 # 2 番目だけ
```

## 5. 画質と時間・サイズの目安

実際のホームビデオ DVD(720x480)での測定です。パソコンの性能で変わります。

| 設定 | 映像 14 分あたりの時間 | ファイルサイズ |
|---|---|---|
| `--height 720 --quality standard` | 約 3 分 | 約 200 MB |
| `--height 1080 --quality high`(既定) | 約 12 分 | 約 620 MB |

- 元が 720x480 なので、1080p は「引き伸ばし」です。映像の情報が増えるわけではなく、ぼやけを抑えて大きな画面で見やすくする効果が中心です
- 速さとサイズを優先するなら 720p / standard、きれいさを優先するなら既定の 1080p / high がおすすめです

### どんな処理をしているか

1. **ちらつき除去:** ビデオカメラ由来の映像に多い、動くところの横縞を消します(自動判定)
2. **ノイズ除去:** ざらつきを少しだけ抑えます
3. **縦横比の補正と拡大:** 4:3 は 1440x1080、16:9 は 1920x1080 になります
4. **軽いシャープ:** 輪郭を少しだけくっきりさせます
5. 出力は H.264(映像)+ AAC(音声)の mp4 です。音声は最初の 1 本だけ入ります

## 6. こんなときは

| 表示・症状 | 原因と対処 |
|---|---|
| `VIDEO_TS も BDMV も見つかりません` | 指定したフォルダが違います。ドライブ直下か、`VIDEO_TS` / `BDMV` を含むフォルダを指定してください |
| `ffprobe を起動できません` | ffmpeg が見つかりません。PATH に追加するか、`--ffmpeg` でパスを指定してください |
| `出力先が既に存在します` | 同じ名前のファイルがあります。別名にするか、上書きしてよければ `--force` を付けてください |
| `変換対象のタイトルがありません` | 10 秒未満のタイトルしかありません。`list` で内容を確認してください |
| `タイトル N は存在しません` | `--title` の番号が違います。`list` で確認してください |
| `映像情報を取得できません` | ディスクの読み取りエラーか、ファイルの破損です。コピーしたフォルダで試すか、ディスクを清掃して再試行してください |
| `ffmpeg が失敗しました` | 続けて表示される ffmpeg のメッセージが原因です。内容を控えて相談してください |
| 動く場面に横縞が残る | `--deinterlace on` を付けて変換し直してください |
| 本編ではないタイトルが変換された | `list` で番号を確認し、`--title N` で指定してください |
| 途中で止めた(Ctrl+C など) | `名前.mp4.partial` という未完成ファイルが残ることがあります。削除して構いません(完成した `.mp4` は作られません) |

変換に失敗したときは、途中のファイルは自動で削除され、既存のファイルも壊れません。

## 7. できないこと(現在の版)

- コピーガード付きディスクの変換
- ISO ファイルの直接読み込み(マウントしてから指定してください)
- ブルーレイのプレイリスト(MPLS)の解析。`.m2ts` ファイル 1 つを 1 タイトルとして扱います
- メニュー・字幕・複数の音声トラックの再現
- AI による超解像(将来の拡張候補です)
- 画面(GUI)での操作
