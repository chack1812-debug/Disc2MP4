# Disc2MP4 設計書 (v0.1 ドラフト)

日付: 2026-11-20 / 状態: Human承認待ち

## 目的と背景

ホームビデオから作成した DVD(VIDEO_TS)・ブルーレイ(BDMV)を、`.mp4` に変換するコマンドラインツールを作る。
対象はコピーガードのない自作ディスクのみ。解像度が低い映像が多いので、単なる形式変換ではなく「見られる画質に整える」ことまで含める。

## ゴール

- VIDEO_TS / BDMV のフォルダを指定すると、本編を判定して mp4(H.264 + AAC)に変換できる
- インターレース解除・拡大・軽いノイズ除去を既定で適用し、低解像度のホームビデオを見やすくする
- ffmpeg 単体で完結し、追加のランタイムを要らない(Rust 製の単一 exe + ffmpeg)

## ノンゴール(v1ではやらない)

- 暗号化(CSS / AACS)の解除。対応もしない
- ISO ファイルの直接読み込み(Windows でマウントしたドライブ/フォルダを指定する運用)
- BD の MPLS プレイリスト解析(v1 は m2ts ファイル単位で扱う)
- AI 超解像(Real-ESRGAN 等)。将来の「高画質モード」として別設計
- GUI(将来、別プロジェクトとして上に載せる可能性はあるが v1 範囲外)
- メニュー・字幕・複数音声トラックの再現

## アンチゴール(動いても失敗とみなすもの)

- 元のディスクや入力ファイルを書き換える、または既存の出力を黙って上書きする
- 本編と無関係なメニュー映像だけを変換して「成功」と報告する

## 制約・前提

- OS は Windows 11。ffmpeg / ffprobe は PATH 上にある(`C:\Program Files (x86)\ffmpeg\bin`)。`--ffmpeg <path>` で上書き可
- 確認済みの ffmpeg の機能: bwdif, yadif, hqdn3d, scale(lanczos), unsharp, concat, libx264, aac, h264_nvenc
- Rust 1.99(cargo 導入済み)

## 採用した作り方(Human承認済み)

- 案A: コマンドラインツール。言語は Rust
- 却下した案: B(GUI アプリ)は作る量が多く、本編自動判定の作り込みが要る。C(ライブラリ+後から画面)は将来の拡張として、内部構造だけ lib と bin に分けて備える(下記)

## 使い方(想定)

```
disc2mp4 list    <ディスクのパス>                 # 変換候補(タイトル)の一覧と長さを表示
disc2mp4 convert <ディスクのパス> [-o 出力先]     # 本編(最長タイトル)を変換
disc2mp4 convert <ディスクのパス> --all           # 全タイトルを個別の mp4 に変換
オプション: --title N / --height 720|1080|keep / --deinterlace auto|on|off
            --quality standard|high / --force / --ffmpeg <path>
```

## 設計

### 構成

1 つのクレート `disc2mp4`、lib + bin。bin は引数解析(clap)と表示だけ。処理は lib に置く。

| モジュール | 責務 |
|---|---|
| `scan` | 入力パスから種別(DVD/BD)を判定し、タイトル一覧を作る |
| `probe` | ffprobe(JSON)で長さ・解像度・SAR・field_order を取得 |
| `plan` | 画質オプションから ffmpeg の引数(フィルタチェーン含む)を組み立てる |
| `run` | ffmpeg を起動し、`-progress pipe:1` から進捗(%)を表示 |

### タイトル判定

- 入力は `VIDEO_TS` / `BDMV` フォルダ自身、またはそれを含む親フォルダのどちらでもよい
- **DVD**: `VTS_nn_1.VOB`, `VTS_nn_2.VOB`… を nn ごとにまとめて 1 タイトルとする。メニュー(`VIDEO_TS.VOB`, `VTS_nn_0.VOB`)は除外。複数ファイルは concat プロトコル(`concat:a|b|c`)で連結して読む
- **BD**: `BDMV\STREAM\*.m2ts` を 1 ファイル = 1 タイトルとする
- 「本編」= 長さ(ffprobe の duration)が最長のタイトル。長さが取れない場合はファイルサイズ合計で代替
- 一覧は番号・長さ・解像度・ファイル構成を表示する。短すぎる(10 秒未満)タイトルは `--all` でも既定では除外する(私の判断)

### 画質処理(既定)

フィルタの順序: デインターレース → ノイズ除去 → 拡大 → シャープ。

1. デインターレース: `auto` は ffprobe の `field_order` がインターレースなら `bwdif=mode=send_frame`(フレームレートは維持)。プログレッシブなら適用しない
2. ノイズ除去: `hqdn3d=2:1.5:3:2.5`(弱め)。強さは `--quality` に関わらず固定とする(画像を溶かさないため。quality の差はエンコード品質 crf/preset だけで付ける)
3. 拡大: 非正方形画素(DVD の 720x480 など)を SAR 補正で正しい縦横比に直したうえで、`--height`(既定 720)へ `scale=...:flags=lanczos`。元より小さくなる指定は拡大しない
4. シャープ: `unsharp=5:5:0.5`(弱め)
5. エンコード: libx264、`standard` = crf 20 / preset medium、`high` = crf 17 / preset slow、`yuv420p`、`+faststart`。音声は AAC 192k

### 出力と安全性

- 出力先の既定は入力フォルダの隣(`<ディスク名>.mp4`、複数なら `_titleNN`)。`-o` で指定
- 既存ファイルがある場合はエラーにして止まる(`--force` で上書き許可)
- 入力は読み取りのみ。エラー時は不完全な出力を削除する

### エラー処理

- ffmpeg / ffprobe が見つからない、VIDEO_TS/BDMV が見つからない、変換対象がない、ffmpeg が非ゼロ終了、のそれぞれに分かりやすい日本語メッセージを出して終了コード非ゼロで終わる

### テスト方針

- `scan`: 一時フォルダに偽の VIDEO_TS/BDMV 構造を作り、メニュー除外・VTS のまとめ・最長判定を検証する
- `plan`: オプションの組み合わせごとに、生成されるフィルタ文字列を検証する(インターレース判定、拡大しない場合、SAR 補正)
- 結合テスト: ffmpeg の lavfi で数秒のテスト用 VOB / m2ts を生成し、変換して mp4 が出来ることと、長さが近いことを確認する(ffmpeg がない環境では skip)
