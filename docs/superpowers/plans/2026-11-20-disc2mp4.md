# Disc2MP4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DVD(VIDEO_TS)/ブルーレイ(BDMV)の自作ディスクを、画質を整えた mp4(H.264+AAC)に変換する Rust 製 CLI `disc2mp4` を作る。

**Architecture:** 1 クレート(lib + bin)。`scan`(タイトル列挙)→`probe`(ffprobe)→`plan`(ffmpeg 引数)→`run`(実行・進捗)の流れを、`commands`(list/convert)が束ね、`main` は clap の引数解析のみ。変換エンジンは外部の ffmpeg/ffprobe。

**Tech Stack:** Rust 1.99、clap(derive)、serde_json、anyhow、dev: tempfile。ffmpeg 8 系(PATH 上、libx264 / bwdif / hqdn3d / unsharp / aac 確認済み)。

**Spec:** `docs/superpowers/specs/2026-11-20-disc2mp4-design.md`

## Global Constraints

- 出力は H.264(libx264)+ AAC 192k、`yuv420p`、`-movflags +faststart`。`standard` = crf 20 / preset medium、`high` = crf 17 / preset slow
- フィルタ順は デインターレース → `hqdn3d=2:1.5:3:2.5` → 拡大(lanczos)→ `unsharp=5:5:0.5`。ノイズ除去の強さは quality に依存させない
- 拡大の既定高さは 720。元より小さくなる指定では拡大しない(縮小しない)
- bwdif は `bwdif=mode=send_frame`。`auto` は ffprobe の field_order が `tt|bb|tb|bt` のときだけ適用
- 10 秒未満のタイトルは既定で変換対象から除外する
- 入力は読み取りのみ。既存の出力は `--force` なしで上書きしない。失敗時は不完全な出力を削除する
- ユーザー向けメッセージ(エラー・進捗)は日本語。コード・コミットメッセージ・コメントは英語でも日本語でもよいが統一する(コミットは英語)
- メニュー(`VIDEO_TS.VOB`, `VTS_nn_0.VOB`)は除外。暗号化の解除・ISO 直接読み込み・MPLS 解析・GUI・AI 超解像は実装しない
- 場所: `D:\UDS\宇摩コードワークス\Disc2MP4`(独立 git リポジトリ。Beads の導入は Human 判断なので本計画では行わない)

## Review Focus

- パスに日本語と空白を含む(実環境 `D:\UDS\宇摩コードワークス\...`)ディスクでも、list/convert が動く(concat 入力を含む)
- 引数が `VIDEO_TS`/`BDMV` 自身でも、それを含む親フォルダでも同じ結果になる。どちらも無ければ分かりやすいエラー
- ffprobe の duration が `N/A`、SAR が `0:1`/`N/A`: 落ちずに、サイズ代替・1:1 扱いで進む
- 出力ファイルが既存: 上書きせずエラー。`--force` で上書き
- ffmpeg が失敗(壊れた入力など): 不完全な mp4 が残らず、非ゼロで終了する。変換対象(10 秒以上)が 0 件のときも同様にエラー

### Task 4: plan(ffmpeg 引数の組み立て)

**Files:**
- Create: `src/plan.rs`(`pub mod plan;`)

**Interfaces:**
- Consumes: `MediaInfo`
- Produces:
  - `enum Deinterlace { Auto, On, Off }`、`enum Quality { Standard, High }`、`enum Height { Keep, Px(u32) }`
  - `struct Options { height: Height, deinterlace: Deinterlace, quality: Quality }` と `impl Default`(720 / Auto / Standard)
  - `pub fn video_filter(info: &MediaInfo, opts: &Options) -> String`
  - `pub fn ffmpeg_args(input: &str, output: &Path, info: &MediaInfo, opts: &Options) -> Vec<String>`

**振る舞い:** `video_filter` は Global Constraints の順に `,` で連結。SAR が 1:1 でなければ拡大とは別に `scale=trunc(iw*sar/2)*2:ih:flags=lanczos,setsar=1` で正方画素にする。拡大は SAR 補正後の高さ < 指定高さのときだけ `scale=-2:<H>:flags=lanczos`。`ffmpeg_args` は `-hide_banner -nostats -progress pipe:1 -y -i <input> -map 0:v:0 -map 0:a:0? -vf <filter> -c:v libx264 -crf … -preset … -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart <output>`。

- [ ] **Step 1: テストを書く**(`MediaInfo` は 720x480 / sar 32:27 / interlaced を基準にする)
  - `interlaced_auto_adds_bwdif_first`: filter が `bwdif=mode=send_frame` で始まる
  - `progressive_auto_has_no_deinterlace`、`on_forces_and_off_suppresses`(Progressive+On → bwdif あり、Interlaced+Off → なし)
  - `order_is_deinterlace_denoise_scale_sharpen`: `bwdif` < `hqdn3d=2:1.5:3:2.5` < `scale=-2:720` < `unsharp=5:5:0.5` の出現位置の大小
  - `no_upscale_when_already_tall_enough`: 1080 の入力・Px(720) → `scale=-2:` を含まない
  - `unit_sar_skips_sar_correction`: sar (1,1) → `setsar=1` を含まない
  - `keep_height_skips_scaling`
  - `quality_maps_to_crf_and_preset`: Standard → `-crf 20 -preset medium`、High → `-crf 17 -preset slow`(引数列の隣接で確認)
  - `args_end_with_output_and_map_audio_optional`: 最後が出力パス、`0:a:0?` を含む
- [ ] **Step 2: 失敗を確認** — `cargo test plan`
- [ ] **Step 3: 実装** — 上記どおり(フィルタは `Vec<String>` に積んで `join(",")`)
- [ ] **Step 4: 成功を確認** — `cargo test plan` → 8 件 PASS
- [ ] **Step 5: コミット** — `git commit -am "feat: build ffmpeg filter chain and arguments"`
